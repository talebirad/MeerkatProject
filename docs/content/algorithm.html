Where to Implement Your Community Mining Algorithm in MeerkatProject

This guide explains where and how to implement your clustering algorithm in MeerkatProject once you have successfully added it to the Community Mining menu.

1. Locate the Algorithm Processing Class

All community mining algorithms are managed by the CommunityMiningAlgorithmDialog class. This class receives the parameters and executes the selected algorithm.

Path:

MeerkatProject/MeerkatLogic/src/algorithms/communitymining/

Find or create a file inside this directory to implement your new algorithm.

Example Implementation File:

If your algorithm is called NewAlgorithm, create a file named:

MeerkatProject/MeerkatLogic/src/algorithms/communitymining/NewAlgorithm.java

2. Implement the Clustering Algorithm

Example: NewAlgorithm.java

package algorithm.graph.communitymining;

import java.util.List;
import datastructure.core.TimeFrame;
import datastructure.core.graph.classinterface.*;
import java.util.ArrayList;
import java.util.HashMap;

public class NewAlgorithmMiner<V extends IVertex, E extends IEdge<V>>
        extends Miner<V, E> {

    public static final String STR_NAME = "NewAlgorithm";
    public static boolean parameter1;
    public static boolean parameter2;
    public static ArrayList<Integer> vertexIDs = new ArrayList<>();
    
    public NewAlgorithmMiner(IDynamicGraph<V, E> pIGraph, TimeFrame tf, String[] parameters) {
        super(pIGraph, tf);
        parameter1 = parameters[0].contains("true");
        parameter2 = parameters[1].contains("true");
        
        String vertexIDs_str = parameters[2].substring("VertexIDs:[".length(), parameters[2].length()-1);
        String[] numberStrs = vertexIDs_str.isEmpty() ? new String[0] : vertexIDs_str.split(",");
        
        vertexIDs.clear();
        for (int i = 0; i < numberStrs.length; i++) {
            vertexIDs.add(Integer.parseInt(numberStrs[i].trim()));
        }
    }

    @Override
    public void run() {
        System.out.println("********* New Algorithm Running *********");
        mineGraph(parameter1, parameter2, vertexIDs);
        if (!running) {
            return;
        }
        updateDataStructure();
        blnDone = true;
    }
    
    public void mineGraph(boolean parameter1, boolean parameter2, ArrayList<Integer> vertexIDs) {
        HashMap<Integer, Integer> results = new HashMap<>();
        
        for (int vertexId : vertexIDs) {
            int communityId = vertexId % 3;
            results.put(vertexId, communityId);
        }
        
        if (!running) {
            return;
        }
        results.keySet().forEach((vertexId) -> {
            int communityId = results.get(vertexId);
            if (hmpCommunities.containsKey(communityId + "")) {
                hmpCommunities.get(communityId + "").add(vertexId);
            } else {
                List<Integer> listofVertices = new ArrayList<>();
                listofVertices.add(vertexId);
                hmpCommunities.put(communityId + "", listofVertices);
            }
        });
    }
    
    @Override
    public String toString() {
        return STR_NAME;
    }
}

What This Code Does:

  1. Receives a list of vertex IDs (nodes from the graph).
  2. Processes the parameters sent from the UI.
  3. Assigns each node to a cluster (using a modulus operation in this example).
  4. Returns a map where each node is assigned a cluster ID.

3. Visualizing the Clustering Output

After execution, the results are passed to the UI for visualization.

Modify CommunityMiningAlgorithmDialog.java to Send Results to UI:

pController.updateGraphWithCommunities(clusteringResult);

This ensures that the graph canvas updates with the detected clusters, each assigned a unique color.

Final Outcome

  • Your NewAlgorithm is now fully implemented and connected to MeerkatProject.
  • The algorithm processes the graph nodes and assigns clusters.
  • The UI updates the visualization to show the clustering results.

Now your community mining algorithm is ready to use!
