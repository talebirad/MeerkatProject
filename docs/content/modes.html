How to Add a New Selection Mode in MeerkatProject

This guide explains how to add a new selection mode to MeerkatProject, enabling users to select vertices in different ways within the graph visualization. We will go through how we added the SIWO Community Search Mode as an example.

1. Define the Selection Mode in ModeConfig.java

Add a new enum value for the selection mode:

public static String SINGLECOMMUNITYSIWOPLUS_MODE_TAG = "SelectSingleCommunitySIWOPLUSMode";
public static String SINGLECOMMUNITYSIWOPLUS_MODE;

// The following enums are used for setting the comparisons
public static enum ModeTypes {
    SELECT,
    VERTEXADD,
    VERTEXMULTIFRAMEADD,
    VERTEXDELETE,
    EDGEADD,
    EDGEDELETE,
    SHORTESTPATH,
    SINGLECOMMUNITYSIWOPLUS
}

2. Selecting the Mode in Code

Activate the selection mode with:

UIInstance.getActiveProjectTab().getActiveGraphTab().setGraphCanvasMode(ModeConfig.ModeTypes.SINGLECOMMUNITYSIWOPLUS);

3. Define the Selection Mode in english.xml

Add a new text entry:

<Modes>
    <SelectMode>Select Mode</SelectMode>
    <VertexAddMode>Vertex Add Mode</VertexAddMode>
    <VertexMultiFrameAddMode>Vertex Multiframe Add Mode</VertexMultiFrameAddMode>
    <VertexDeleteMode>Vertex Delete Mode</VertexDeleteMode>
    <EdgeAddMode>Edge Add Mode</EdgeAddMode>
    <EdgeDeleteMode>Edge Delete Mode</EdgeDeleteMode>
    <ShortestPathMode>Shortest Path Mode</ShortestPathMode>
    <SelectSingleCommunitySIWOPLUSMode>SIWO Local Search Mode</SelectSingleCommunitySIWOPLUSMode>
</Modes>

4. Add New Fields in ModeInformationConfig.java

Update to store and manage the selection mode information:

public class ModeInformationConfig {
    
    public static String SELECTSINGLECOMMUNITYSIWOPLUS_TAG = "SelectSingleCommunitySIWOPLUS";
    public static String SELECTSINGLECOMMUNITYSIWOPLUS;
}

5. Modify GraphCanvasModeFactory.java to Handle the New Mode

Add a case for the new mode:

public class GraphCanvasModeFactory {
    public GraphCanvasMode getGraphCanvasMode(ModeTypes pstrCanvasMode){
        switch (pstrCanvasMode) {
            case SELECT:
                return new NormalSelectionMode();
            case VERTEXADD:
                return new AddVertexMode();
            case EDGEADD:
                return new AddEdgeMode();
            case VERTEXMULTIFRAMEADD:
                return new AddVertexMultipleTimeFramesMode();
            case VERTEXDELETE:
                return new DeleteVertexMode();
            case EDGEDELETE:
                return new DeleteEdgeMode();
            case SHORTESTPATH:
                return new ShortestPathMode();
            case SINGLECOMMUNITYSIWOPLUS:
                return new SingleNodeCommunityMode(); // New functionality
            default:
                return new NormalSelectionMode(); 
        }
    }
}

6. Implement the Logic Class for the New Mode

Create the logic class (for example, SingleNodeCommunityMode.java):

public class SingleNodeCommunityMode extends GraphCanvasMode {

    @Override
    public void handleMouseClick(MouseEvent event) {
        System.out.println("Single Node Community Mode Activated");
        GraphNode selectedNode = getNodeAt(event.getX(), event.getY());
        if (selectedNode != null) {
            performSiwoPlusSearch(selectedNode);
        }
    }

    private void performSiwoPlusSearch(GraphNode node) {
        System.out.println("Performing SIWO+ Search on Node: " + node.getId());
    }
}

7. Load Mode Data Information

Ensure that ModeConfig and ModeInformationConfig correctly load the mode settings from the XML configuration:

ModeConfig.SINGLECOMMUNITYSIWOPLUS_MODE = eOptionsElement.getElementsByTagName(ModeConfig.SINGLECOMMUNITYSIWOPLUS_MODE_TAG).item(0).getTextContent();
ModeInformationConfig.SELECTSINGLECOMMUNITYSIWOPLUS = eOptionsElement.getElementsByTagName(ModeInformationConfig.SELECTSINGLECOMMUNITYSIWOPLUS_TAG).item(0).getTextContent();

8. Testing the Feature

  • Run the application and open the selection mode menu.
  • Select the new SIWO+ Selection mode.
  • Verify that it behaves as expected.

Now you can extend selection functionality in MeerkatProject!
