How to Add an Option to the Vertex Right-Click Menu in MeerkatProject

This guide explains how to add a new option to the right-click menu of a vertex in MeerkatProject, allowing users to trigger actions directly on selected vertices in the graph.

1. Add a Text Entry in english.xml

Define the text for your new option under the NodeContextMenu tag:

<NodeContextMenu>
    <SelectCommunity>Select Same-color Nodes</SelectCommunity>
</NodeContextMenu>

2. Define the Constant in LangConfig.java

Add a constant to reference the text entry:

public static String NODECTX_COMMUNITY_TAG = "SelectCommunity";

3. Update LanguageXML.java to Load the New Option

Retrieve the translated text from english.xml:

String selectCommunityText = eOptionsElement.getElementsByTagName(LangConfig.NODECTX_COMMUNITY_TAG).item(0).getTextContent();

4. Add Necessary Fields in VertexContextConfig.java

Update the file to store and manage the new context menu option:

public class VertexContextConfig {
    
    private static String VERTEX_SELECT_COMMUNITY;
    
    public static String getVertexSelectCommunityText() {
        return VERTEX_SELECT_COMMUNITY;
    }
    
    public static void Instantiate(String pstrVertexSelectCommunityText) {
        VERTEX_SELECT_COMMUNITY = pstrVertexSelectCommunityText;
    }
}

5. Locate the Vertex Menu Code

The right-click menu for vertices is handled in the Graph UI components (typically in VertexContextMenu.java).

6. Add a New Menu Item

Modify VertexContextMenu.java to add a new option:

import javafx.scene.control.MenuItem;
import config.VertexContextConfig;

public class VertexContextMenu extends ContextMenu {
    
    public VertexContextMenu(Vertex vertex) {
        super();
        
        // Existing menu items
        MenuItem miViewDetails = new MenuItem("View Details");
        MenuItem miDelete = new MenuItem("Delete Vertex");
        
        // New menu item
        MenuItem miSelectCommunity = new MenuItem(VertexContextConfig.getVertexSelectCommunityText());
        miSelectCommunity.setOnAction(event -> handleSelectCommunity(vertex));
        
        this.getItems().addAll(miViewDetails, miDelete, miSelectCommunity);
    }
    
    private void handleSelectCommunity(Vertex vertex) {
        System.out.println("Select Community option chosen for vertex: " + vertex.getId());
        // Implement your feature here
    }
}

7. Implement the Functionality

Modify the handleSelectCommunity method to perform your custom action. For example, to select all nodes with the same color:

private void handleSelectCommunity(Vertex vertex) {
    Graph graph = vertex.getGraph();
    String color = vertex.getColor();
    
    List<Vertex> sameColorNodes = graph.getVertices().stream()
        .filter(v -> v.getColor().equals(color))
        .collect(Collectors.toList());
    
    sameColorNodes.forEach(v -> v.setSelected(true));
    System.out.println("Selected " + sameColorNodes.size() + " nodes with the same color.");
}

8. Testing the Feature

  • Run the application and right-click a vertex.
  • Verify that the new option appears in the context menu.
  • Click it and check if the nodes of the same color are selected.

Now the vertex right-click menu is extended!
